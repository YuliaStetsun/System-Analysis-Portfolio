# approveParticipationsEvents — Метод подтверждения/отказа от участия

**URL:** `POST axbit.com/events/participations`

## Входные параметры:

| № | Наименование | Тип данных | Мн-ть | Описание |
| :--- | :--- | :--- | :--- | :--- |
| 1 | userId | integer | 1..1 | ИД пользователя |
| 2 | eventId | integer | 1..1 | ИД мероприятия |
| 3 | action | boolean | 1..1 | Возможные значения:
• 1 (true) - подтверждение участия в мероприятии
• 2 (false) - отказ от участия в мероприятии |

## Выходные параметры:

Отсутствуют

## Описание сценария метода:

**Шаг 1.** 
Система валидирует входные параметры на соответствие заявленным типам данных и наличие обязательных параметров. 
Если проверка не пройдена, система возвращает ошибку **B001**.

**Шаг 2.** 
Система находит запись в таблице `users` по условию:
* `users.id = input userId`

Если запись найдена, система переходит к следующему шагу.
Если запись не найдена, система возвращает ошибку **B002**.

**Шаг 3.** 
Система находит запись в таблице `events` по условию:
* `events.id = input eventId`

Если запись найдена, система переходит к следующему шагу.
Если запись не найдена, система возвращает ошибку **B003**.

**Шаг 4.** 
Система находит запись в таблице `members` по условию:
* `members.users_id = input userId`
* `members.events_id = input eventId`

Если запись найдена, система возвращает ошибку **B004**.
Если запись не была найдена, система переходит к следующему шагу.

**Шаг 5.** 
Система редактирует запись в таблице `members` по условию:
* `members.status_events_id =`
  * `true`, если **input action = 1**
  * `false`, если **input action = 2**

**Шаг 6.** 
Система возвращает HTTP-код 200 и переходит к последнему шагу.

**Шаг 7.** 
Сценарий завершен.

## Таблица ошибок:

| Код ошибки | HTTP-код | Наименование ошибки | Категория |
| :--- | :--- | :--- | :--- |
| B001 | 422 | Ошибка в валидации входных параметров | BusinessFault |
| B002 | 422 | Пользователь с userId = &lt;input userId&gt; не найден в системе | BusinessFault |
| B003 | 422 | Мероприятие с eventId = &lt;input eventId&gt; не найдено в системе | BusinessFault |
| B004 | 422 | По переданному ИД пользователя не было отправлено приглашение к участию в мероприятии | BusinessFault |
| U001 | 500 | Непредвиденная ошибка | UnexpectedFault |
