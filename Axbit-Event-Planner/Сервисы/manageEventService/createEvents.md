# createEvents — Метод создания мероприятия

**URL:** `POST axbit.com/events`

## Входные параметры:

| № | Наименование | Тип данных | Мн-ть | Описание |
| :--- | :--- | :--- | :--- | :--- |
| 1 | eventName | string | 1..1 | Наименование мероприятия |
| 2 | eventDescription | string | 0..1 | Описание мероприятия |
| 3 | eventDate | string (format date) | 1..1 | Дата проведения мероприятия |
| 4 | location | string | 1..1 | Место проведения мероприятия |
| 5 | members | array | 1..* | Сведения об участниках |
| 5.1 | memberId | integer | 1..1 | Идентификатор записи участника |
| 6 | authorId | integer | 1..1 | Идентификатор автора |

## Выходные параметры:

Отсутствуют

## Описание сценария метода:

**Шаг 1.**
Система валидирует входные параметры на соответствие заявленным типам данных и наличие обязательных параметров. 
Если проверка не пройдена, система возвращает ошибку **B001**.

**Шаг 2.**
Система находит запись в таблице `users` по условию:
* `users.id = input authorId`

Если запись найдена, система переходит к следующему шагу.
Если запись не найдена, система возвращает ошибку **B002**.

**Шаг 3.**
Система создает запись в таблице `events` по условию:
* `id` = автоинкремент
* `name` = input eventName
* `description` = input eventDescription
* `date` = input eventDate
* `location` = input location
* `author_id` = input authorId
* `date_created` = Текущие дата и время
* `archived` = false
* `date_archived` = null

**Шаг 4.**
*Данный шаг выполняется для каждого переданного input memberId.*
Система создает запись в таблице `members` по условию:
* `members.id` = автоинкремент
* `members.users_id` = input memberId
* `members.events_id` = events.id
* `members.status_events_id` = null

**Шаг 5.**
Система возвращает HTTP-код 200 и переходит к последнему шагу.

**Шаг 6.**
Сценарий завершен.

| Код ошибки | HTTP-код | Наименование ошибки | Категория |
| :--- | :--- | :--- | :--- |

| B002 | 422 | Пользователь с user.id = &lt;input userId&gt; не найден в системе | BusinessFault |
| U001 | 500 | Непредвиденная ошибка | UnexpectedFault |
