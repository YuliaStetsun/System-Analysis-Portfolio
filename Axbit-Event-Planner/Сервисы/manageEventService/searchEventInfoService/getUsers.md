# getUsers — Метод получения всех сотрудников компании для отображения в раскрывающемся списке

**URL:** `GET axbit.com/users`

## Входные параметры:

Отсутствуют

## Выходные параметры:

| № | Наименование | Тип данных | Мн-ть | Описание |
| :--- | :--- | :--- | :--- | :--- |
| 1 | users | array | 1..* | Сведения о пользователях |
| 1.1 | userId | integer | 1..1 | ИД пользователя |
| 1.2 | userFirstName | string | 1..1 | Имя пользователя |
| 1.3 | userLastName | string | 1..1 | Фамилия пользователя |

## Описание сценария метода:

**Шаг 1.** 
Система находит все записи в таблице `users`.

Если ни одна запись не найдена, система возвращает ошибку **B001**.
Если хотя бы одна запись найдена, система переходит к следующему шагу.

**Шаг 2.** 
*Данный шаг выполняется для каждой найденной записи `users`*

Система добавляет в выходные параметры следующие значения:
* `userId` = `users.id`
* `userFirstName` = `users.first_name`
* `userLastName` = `users.last_name`

**Шаг 3.** 
Система возвращает HTTP-код 200 и выходные параметры.

**Шаг 4.** 
Сценарий завершен.

## Таблица ошибок:

| Код ошибки | HTTP-код | Наименование ошибки | Категория |
| :--- | :--- | :--- | :--- |
| B001 | 422 | Пользователи не найдены в системе | BusinessFault |
| U001 | 500 | Непредвиденная ошибка | UnexpectedFault |
