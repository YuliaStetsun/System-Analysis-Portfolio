# getUserEvents — Метод получения списка моих мероприятий

**URL:** `GET axbit.com/events/{userId}`

## Входные параметры:

| № | Наименование | Тип данных | Мн-ть | Описание |
| :--- | :--- | :--- | :--- | :--- |
| 1 | userId | integer | 1..1 | ИД пользователя |

## Выходные параметры:

| № | Наименование | Тип данных | Мн-ть | Описание |
| :--- | :--- | :--- | :--- | :--- |
| 1 | events | array | 0..* | Сведения о мероприятиях |
| 1.1 | eventId | integer | 1..1 | ИД мероприятия |
| 1.2 | eventName | string | 1..1 | Наименование мероприятия |
| 1.3 | eventDate | string (format date) | 1..1 | Дата проведения мероприятия |
| 1.4 | location | string | 1..1 | Место проведения мероприятия |
| 1.5 | eventDateCreated | string (format date) | 1..1 | Дата создания мероприятия |
| 1.6 | authorId | integer | 1..1 | ИД автора мероприятия |
| 1.7 | authorFirstName | string | 1..1 | Имя автора мероприятия |
| 1.8 | authorLastName | string | 1..1 | Фамилия автора мероприятия |
| 1.9 | eventStatusId | integer | 1..1 | Идентификатор записи статуса участия в мероприятии |
| 1.10 | eventStatusTitle | string | 1..1 | Наименование статуса участия в мероприятии |

## Описание сценария метода:

**Шаг 1.** 
Система валидирует входные параметры на соответствие заявленным типам данных и наличие обязательных входных параметров.
Если проверка не пройдена, система возвращает ошибку **B001**.

**Шаг 2.** 
Система находит запись в таблице `members` по условию:
* `members.user_id = input userId`

Если ни одной записи не было найдено, система возвращает пустой ответ.
Если хотя бы одна запись была найдена, система переходит к следующему шагу.

**Шаг 3.** 
*Шаги 3.3 - 3.7 выполняются для каждой найденной записи `events`*

**3.1.** Система добавляет в выходные параметры следующие значения:
* `eventStatusId` = `members.status_events_id`

**3.2.** Система находит запись в таблице `status_events` по условию:
* `status_events.title = members.status_events.title`

**3.3.** Система добавляет в выходные параметры следующие значения:
* `eventStatusTitle` = `status_events.title`

**3.4.** Система находит запись в таблице `events` по условию:
* `events.id = members.events_id`

**3.5.** Система добавляет в выходные параметры следующие значения:
* `eventId` = `events.id`
* `eventName` = `events.name`
* `eventDate` = `events.date`
* `location` = `events.location`
* `eventDateCreated` = `events.date_created`

**3.6.** Система находит запись в таблице `users` по условию:
* `users.id = events.author_id`

**3.7.** Система добавляет в выходные параметры следующие значения:
* `authorId` = `events.users_id`
* `authorFirstName` = `events.users.first_name`
* `authorLastName` = `events.users.last_name`

**Шаг 4.** 
Сценарий завершен.

| U001 | 500 | Непредвиденная ошибка | UnexpectedFault |
