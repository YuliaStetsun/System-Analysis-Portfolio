Проект «Axbit  — Планировщик мероприятий»
 
Итоговый проект по курсу «Системный анализ». Разработка проектной документации для системы планирования мероприятий.
 
🎯 Задача проекта
 
Спроектировать систему для создания, просмотра и управления корпоративными мероприятиями на основе готового дизайн-макета. 
 
📂 Состав проекта (структура)
 
1. Архитектура системы
• Физическая модель данных — описание таблиц, типов данных и связей.
• ER-диаграмма (схема БД) — визуальное отображение структуры базы данных. 
2. Сервисы «Axbit. Планировщик мероприятий»
 
В рамках проектирования Бэкенда (REST/JSON) описаны следующие сервисы и методы:
 
manageEventService — сервис управления мероприятиями:
• createEvents — Метод создания мероприятия.
• approveParticipationsEvents — Метод подтверждения/отказа от участия.
• deleteEvents — Метод удаления мероприятия. 
searchEventInfoService — сервис поиска и получения информации:
• getUserEvents — Метод получения списка моих мероприятий.
• getEvents — Метод получения информации по конкретному мероприятию.
• getUsers — Метод получения всех сотрудников компании (для выпадающего списка). 
(Для каждого метода подготовлены: входные/выходные параметры, URL, описание сценария и таблица с ошибками).
 
3. Sequence-диаграммы
 
Описаны сценарии взаимодействия и построены Sequence-диаграммы для процессов (включая альтернативные сценарии):
• Просмотр списка мероприятий.
• Просмотр детальной информации о мероприятии. 
4. Экранные формы
 
Описаны экранные формы для следующих процессов:
• «Создание мероприятия».
• «Получение информации по конкретному мероприятию».
• «Удаление мероприятия».
